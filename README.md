# HTS Medical Laboratory Website

Premium responsive React/Vite landing page built from the supplied HTS Medical Laboratory logo and flyer.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main content
- Clinical Chemistry
- Scan Services
- Haematology and Blood Group Serology
- Medical Microbiology
- Pre-Employment and STD Screening
- Know Your Number
- Full Body Massage
- Blood Banking
